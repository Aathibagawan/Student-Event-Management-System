# ACE Events – Frontend (React + Vite + Tailwind CSS)

```bash
npm install
cp .env.example .env     # VITE_API_URL=http://localhost:8000/api
npm run dev              # http://localhost:5173
npm test                 # Vitest
npm run build            # production build in dist/
```
Pages are lazy-loaded (`src/routes/AppRoutes.jsx`). See the root `README.md` for architecture.
